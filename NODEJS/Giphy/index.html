Buscador de GIFs

GIPHY API · demo

Listo para comenzar.

📋 En este proyecto hemos aprendido a integrar una API pública (GIPHY) en una página web y a mostrar resultados de forma dinámica usando JavaScript. Hemos trabajado con los endpoints GET https://api.giphy.com/v1/gifs/search y GET https://api.giphy.com/v1/gifs/trending, que devuelven un array de objetos con la información de cada GIF (URL, título y metadatos). Se ha utilizado fetch() junto con async/await para realizar las peticiones, aplicando try/catch para manejar errores y construyendo las URLs de forma dinámica mediante parámetros como api_key, q y limit. En la parte visual, hemos creado tarjetas accesibles con título, imagen y enlace al GIF original, empleando loading="lazy" para mejorar el rendimiento y referrerpolicy="no-referrer" para mayor seguridad. Por último, se ha diseñado una interfaz responsive con un grid adaptable, mensajes de estado claros (cargando / error / sin resultados) y retroalimentación accesible mediante aria-live y aria-busy. En conjunto, este ejercicio demuestra la capacidad de consumir APIs, procesar datos JSON y renderizarlos en el DOM aplicando buenas prácticas de usabilidad, accesibilidad y diseño limpio.

Hecho con ❤️ y la GIPHY API.
