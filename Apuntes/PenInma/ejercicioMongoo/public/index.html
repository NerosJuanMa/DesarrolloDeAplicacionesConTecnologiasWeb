📚 Manual Rápido - Conceptos Aprendidos

🔄 De JSON a MongoDB

📄 Antes (JSON)

  • Datos en archivo estático
  • fs.readFileSync()
  • Modificar array y escribir archivo
  • Sin validaciones automáticas

🗄️ Ahora (MongoDB)

  • Datos en base de datos dinámica
  • Modelo.find(), .save(), etc.
  • Operaciones CRUD directas
  • Validaciones con Schema

🔑 Conceptos Clave

  • Schema: Define la estructura de los documentos
  • Modelo: Interfaz para interactuar con la colección
  • CRUD: Create, Read, Update, Delete
  • Mongoose: ODM que facilita el trabajo con MongoDB
