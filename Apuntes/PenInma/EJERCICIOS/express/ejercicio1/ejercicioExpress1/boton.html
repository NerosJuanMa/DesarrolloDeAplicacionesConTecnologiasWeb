🌐 Conexión Front + Servidor Express

Este ejercicio demuestra cómo nuestro frontend (HTML + JS) puede comunicarse con un servidor Express en Node.js para intercambiar datos reales mediante fetch(). ¡Hemos dado el salto de Node “puro” a Express! 



    

  
📘 Mis avances con Express

  

    En este ejercicio he dado el salto a Express, un framework que
    simplifica enormemente la creación de servidores en Node.js.  
    A partir de ahora puedo definir rutas de forma clara y organizada, sin tener que
    manejar manualmente los objetos req y res.
  

  

    Mi servidor (servidor.js) incluye varias rutas: 
    /, /info, /tienda y 
    /contacto. Cada una devuelve un tipo de respuesta distinta:
    texto o JSON según el caso.
  

  

    Desde el frontend (index.html), utilizo 
    fetch() para comunicarme con el servidor y mostrar los datos 
    en pantalla. Si la respuesta es JSON, la convierto con 
    .json(); si es texto o HTML, la muestro directamente en el 
    contenedor correspondiente.
  

  

    Además, he aprendido a usar el middleware CORS para 
    permitir peticiones desde el navegador, y a crear botones accesibles que 
    invocan cada ruta del backend.
  

  

    Este ejercicio marca un paso importante en mi formación: ahora comprendo 
    cómo se conectan el lado del cliente y el lado del servidor en una 
    arquitectura web moderna.  
    ¡Mi primer proyecto Express completo! 🚀
