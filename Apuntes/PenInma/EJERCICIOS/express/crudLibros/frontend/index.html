🚀 Mi avance hacia el desarrollo Full Stack

Este proyecto representa un paso decisivo en mi formación como desarrolladora web full stack. Por primera vez he creado una aplicación completa que conecta un frontend (HTML, CSS y JavaScript) con un backend desarrollado con Node.js y Express.

En el lado del servidor he aprendido a estructurar una API RESTful, gestionando las rutas y métodos HTTP (GET, POST, PUT y DELETE) para implementar un CRUD funcional que permite crear, leer, actualizar y eliminar libros. Además, he configurado middlewares para interpretar JSON y habilitar CORS, comprendiendo la importancia de la comunicación entre diferentes orígenes.

La persistencia de los datos se realiza mediante un archivo libros.json que actúa como una base de datos local. Gracias a ello, he podido interiorizar cómo se almacenan los datos del lado del servidor y cómo mantener su integridad durante las operaciones de escritura y lectura. Este conocimiento será fundamental cuando dé el salto a bases de datos reales como MySQL o MongoDB.

En la parte del cliente he trabajado con fetch() para consumir los endpoints del backend, aprendiendo a manejar las promesas, gestionar los estados de carga y mostrar la información en una tabla dinámica. También he diseñado un formulario accesible que permite añadir o modificar registros en tiempo real, reforzando mi comprensión de cómo interactúan los datos entre el cliente y el servidor.

Desde el punto de vista visual y de experiencia de usuario, he aplicado una paleta lila y blanca que aporta armonía y claridad, cuidando los detalles de diseño, legibilidad y accesibilidad (contraste, foco visible, estructura semántica, etc.). Estos principios son esenciales en el desarrollo front-end profesional.

Este ejercicio no solo me ha permitido consolidar los conocimientos adquiridos en módulos anteriores (HTML, CSS, JavaScript y fundamentos de Node.js), sino que me ha enseñado a pensar de forma estructurada, entendiendo la arquitectura cliente-servidor como un todo. Ahora soy capaz de desarrollar una aplicación completa desde cero, comprender el flujo de datos y anticipar los posibles errores.

En resumen, esta práctica marca el inicio de mi camino hacia el desarrollo full stack: he aprendido a comunicar dos mundos —el del frontend y el del backend— y a crear aplicaciones dinámicas, escalables y mantenibles. A partir de aquí, mi siguiente meta es integrar una base de datos real y profundizar en la autenticación y seguridad de las APIs.

💡 Este proyecto simboliza mi evolución de estudiante a creadora: ya no consumo APIs, las construyo.
