# 📋 Curso de Seguros - Manual Online

## 🎓 Descripción
Curso completo e interactivo sobre seguros desarrollado en HTML, CSS y JavaScript. Incluye 4 módulos principales con contenido detallado, casos prácticos y sistema de evaluación.

## 🏗️ Estructura del proyecto

```
curso-seguros/
├── index.html                 # Página principal e índice
├── css/
│   └── styles.css            # Estilos con colores azul y verde
├── js/
│   └── main.js               # Funcionalidad principal y sistema de tests
├── modulos/
│   ├── modulo1-1.html        # 1.1 Elaboración de productos
│   ├── modulo1-2.html        # 1.2 La póliza de seguros
│   ├── modulo1-3.html        # 1.3 Bases técnicas y tarifas
│   ├── modulo1-4.html        # 1.4 Documentos y suma asegurada
│   ├── modulo2-1.html        # 2.1 Incendios: coberturas
│   ├── modulo3-3.html        # 3.3 Autos: coberturas
│   ├── modulo4-2.html        # 4.2 Seguros de vida
│   └── [más páginas...]      # Resto de temas
└── tests/
    ├── test-modulo1.html     # Test de evaluación Módulo 1
    ├── test-modulo2.html     # Test de evaluación Módulo 2
    └── [más tests...]        # Tests de otros módulos
```

## 🚀 Cómo usar el curso

### Instalación
1. Descargar todos los archivos manteniendo la estructura de carpetas
2. Abrir `index.html` en cualquier navegador web moderno
3. No requiere servidor web, funciona localmente

### Navegación
- **Inicio:** `index.html` contiene la introducción y el índice completo
- **Módulos:** Cada tema es una página independiente con navegación
- **Tests:** Sistema de evaluación al final de cada módulo
- **Progreso:** Se guarda automáticamente en localStorage del navegador

### Funcionalidades
- ✅ **Navegación intuitiva** entre módulos y temas
- ✅ **Sistema de progreso** que guarda el avance automáticamente
- ✅ **Tests interactivos** con puntuación y revisión de respuestas
- ✅ **Responsive design** compatible con móviles y tablets
- ✅ **Destacado de términos** técnicos importantes
- ✅ **Casos prácticos** en cada módulo
- ✅ **Certificado de completión** al finalizar

## 🎨 Características del diseño

### Colores
- **Azul principal:** #2c3e50 (títulos, navegación)
- **Azul claro:** #3498db (acentos, enlaces)
- **Verde principal:** #27ae60 (botones de acción)
- **Verde claro:** #2ecc71 (hover, éxito)

### Tipografía
- **Fuente:** Segoe UI, Tahoma, Geneva, Verdana, sans-serif
- **Títulos:** Jerárquicos con colores diferenciados
- **Texto:** Justificado, tamaño 1.1rem para mejor legibilidad

### Efectos visuales
- Gradientes de fondo azul-verde
- Animaciones CSS suaves
- Tarjetas con sombras y efectos hover
- Barras de progreso animadas

## 🔧 Funcionalidades técnicas

### JavaScript
- **Clase CursoSeguros:** Gestiona toda la funcionalidad
- **Sistema de navegación:** Entre módulos y temas
- **Gestión de progreso:** localStorage para persistencia
- **Tests interactivos:** Evaluación y resultados
- **Responsive:** Adaptación automática a pantalla

### CSS
- **Variables CSS:** Para colores consistentes
- **Flexbox y Grid:** Layout moderno y flexible
- **Media queries:** Responsive design
- **Animaciones:** Transiciones suaves

### HTML
- **Semántico:** Estructura correcta y accesible
- **Meta tags:** SEO y responsive
- **Navegación:** Breadcrumbs y menús consistentes

## 📊 Sistema de evaluación

### Tests
- **Por módulo:** Test específico para cada módulo
- **Preguntas:** Tipo test con 4 opciones
- **Puntuación:** Mínimo 70% para aprobar
- **Revisión:** Posibilidad de revisar respuestas
- **Repetición:** Sin límite de intentos

### Certificación
- **Progreso:** Seguimiento automático del avance
- **Certificado:** Generación automática al completar
- **Estadísticas:** Puntuaciones por módulo
