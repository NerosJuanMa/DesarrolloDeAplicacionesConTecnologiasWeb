Tema 3

Tipos de datos en MongoDB (versión fácil)

Lo esencial para empezar: texto, número, sí/no, listas, objetos, identificadores y fechas. Ejemplos cortos para crear, buscar y actualizar.

🏠 Inicio ⬅ Tema anterior Siguiente tema ➜

📘 1) Antes de nada: JSON que escribes, BSON que guarda

Tú escribirás los datos como JSON (con llaves y comas). MongoDB los guarda por dentro como BSON (binario rápido). No te preocupes: tú sigues usando JSON.

{"nombre":"Ana","edad":28,"activo":true}

🧱 2) Tipos básicos que usarás ya

📝 Texto — String

Palabras, correos, ciudades… (siempre entre comillas).

db.alumnos.insertOne({ nombre: "Ana", email: "ana@mail.com" })
db.alumnos.find({ nombre: "Ana" })

🔢 Número — Number

Edades, notas, precios… (sin comillas).

db.alumnos.insertOne({ nombre: "Luis", edad: 22, nota: 8.5 })
db.alumnos.find({ edad: { $gte: 18 } })

✅ Sí/No — Boolean

db.alumnos.insertOne({ nombre: "Marta", activo: true })
db.alumnos.find({ activo: true })

📦 Lista — Array

Varios valores en un mismo campo.

db.alumnos.insertOne({ nombre: "Sofía", habilidades: ["JS","MongoDB"] })
db.alumnos.find({ habilidades: "MongoDB" })

🏠 Objeto — Object

Información dentro de información.

db.alumnos.insertOne({
  nombre: "Pedro",
  direccion: { ciudad: "Sevilla", cp: "41001" }
})
db.alumnos.find({ "direccion.ciudad": "Sevilla" })

🆔 Identificador — ObjectId

MongoDB crea _id automáticamente (único). Para buscar por un id en la consola:

db.alumnos.find({ _id: ObjectId("507f1f77bcf86cd799439011") })

🚫 Vacío — null

Campo sin dato (por ahora).

db.alumnos.insertOne({ nombre: "Leo", telefono: null })

🗓️ 3) Fechas sin líos (mini-guía)

Hay dos formas comunes de guardar fechas:

  1. Como texto (fácil): ideal para mostrar. Formato recomendado: "AAAA-MM-DD" (ej. "2025-11-05").
  2. Como fecha real (Date): ideal para filtrar por rangos de días/meses/años.

➊ Guardar como texto (fácil y suficiente para mostrar)

db.alumnos.insertOne({ nombre:"Irene", fechaRegistro: "2025-01-15" })
db.alumnos.find({ fechaRegistro: "2025-01-15" })

➋ Guardar como Date (para filtros por fechas)

db.alumnos.insertOne({ nombre:"Irene", alta: new Date("2025-01-15") })

// Buscar de 1 a 31 de enero de 2025
db.alumnos.find({
  alta: { $gte: new Date("2025-01-01"), $lt: new Date("2025-02-01") }
})

Tips rápidos:

  • Si solo muestras la fecha, usa texto. Si vas a “buscar por meses/días”, usa Date.
  • Formato cómodo de texto: "AAAA-MM-DD".
  • En Date usa siempre el formato ISO ("2025-01-15") para evitar líos de zona horaria.

🔎 4) Recetas de búsqueda muy comunes

Por nombre (texto)

db.alumnos.find({ nombre: "Ana" })

Mayores de edad

db.alumnos.find({ edad: { $gte: 18 } })

Tiene “MongoDB”

db.alumnos.find({ habilidades: "MongoDB" })

✍️ 5) Actualizar sin miedo

Cambiar un dato

db.alumnos.updateOne(
  { nombre: "Ana" },
  { $set: { ciudad: "Córdoba" } }
)

Sumar 1 a la edad

db.alumnos.updateOne(
  { nombre: "Luis" },
  { $inc: { edad: 1 } }
)

Añadir a una lista

// evita duplicados en la lista
db.alumnos.updateOne(
  { nombre: "Sofía" },
  { $addToSet: { habilidades: "Node.js" } }
)

💡 6) Consejos rápidos

  • Texto siempre entre comillas. Número y booleano, sin comillas.
  • Usa el mismo tipo en todos los documentos (si edad es número, que siempre lo sea).
  • Para enseñar una fecha, texto es cómodo. Para filtrar por rangos, usa Date.
  • No te compliques con objetos muy profundos: 1–2 niveles suelen bastar.

🧪 7) Mini-práctica (10 minutos)

  1. Crea la colección alumnos.
  2. Inserta 3–5 documentos variando: edad, activo, habilidades, direccion.ciudad y una fecha (prueba texto y Date).
  3. Busca: “alumnos activos que tengan ‘MongoDB’”.
  4. Actualiza: añade “Node.js” a quien tenga “MongoDB”.
// ejemplo consulta del paso 3
db.alumnos.find({ activo: true, habilidades: "MongoDB" })

💬 8) Cierre
