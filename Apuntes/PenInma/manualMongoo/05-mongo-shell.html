Tema 5

Registro en MongoDB Atlas (online) y uso desde shell

Crea tu cuenta gratuita, entiende qué es un clúster y consigue tu cadena de conexión. Usaremos Atlas online porque es sencillo, rápido y no requiere instalar nada.

🏠 Inicio ⬅ Tema anterior Siguiente tema ➜

Objetivos de aprendizaje

Que el alumnado sea capaz de conectar a su cluster Atlas desde mongosh y ejecutar un CRUD completo (insertar, leer, actualizar y borrar) sobre su propia base de datos.

  • Crear usuario y permitir IP en Atlas.
  • Instalar y probar mongosh.
  • Conectar con URI mongodb+srv de forma segura.
  • Aplicar CRUD: insertOne, insertMany, find, updateOne/updateMany, deleteOne/deleteMany.

1) Preparación en MongoDB Atlas

Antes de usar la consola, necesitamos que tu cluster en Atlas acepte conexiones y que exista un usuario de base de datos.

1.1 Crear usuario de base de datos

  1. Entra en Database Access → Add New Database User.
  2. Elige Password y define DB_USERNAME y DB_PASSWORD.
  3. Rol recomendado para pruebas: Atlas Admin o Read and write to any database (mejor restringir después).

1.2 Permitir tu IP

  1. Ve a Network Access → Add IP Address.
  2. Opción rápida: Allow Access From Anywhere (0.0.0.0/0) (solo para desarrollo).
  3. Mejor opción: añadir tu IP actual (más seguro).

1.3 Obtener la cadena de conexión

  1. En Database → Connect → Drivers.
  2. Copia la URI mongodb+srv://... (driver Node 5.x también vale para mongosh).
mongodb+srv://<DB_USERNAME>:<DB_PASSWORD>@<NOMBRE_CLUSTER>.mongodb.net/?retryWrites=true&w=majority&appName=<APP>

Más cómodo si añades el nombre de tu base: .../tienda?retryWrites=true...

Seguridad: No pegues contraseñas con caracteres sin codificar en la URL. Prefiere que mongosh te pida la contraseña o usa variables de entorno.

2.1 Instalar mongosh y conectarte con tu cuenta de MongoDB Atlas

MongoDB Shell (mongosh) es la consola oficial para conectarte a MongoDB desde tu ordenador. Puedes instalarla de dos formas: desde la web de descargas o directamente al iniciar sesión en tu cuenta de MongoDB Atlas.

🧭 Paso previo — Inicia sesión en tu cuenta

  1. Ve a la página oficial de acceso: https://account.mongodb.com/account/login
  2. Introduce tu correo y contraseña de Atlas.
  3. Accede a tu proyecto (Project) y haz clic en el botón verde Connect del clúster que tengas creado.
  4. Selecciona la opción Connect with MongoDB Shell.
💡 Consejo: esta opción es la más cómoda, porque Atlas te mostrará directamente el comando exacto que debes usar en tu terminal, incluyendo el nombre de tu clúster y la base por defecto. 
mongosh "mongodb+srv://<tu_cluster>.mongodb.net/<nombre_base>" --username <tu_usuario>

Esa cadena de conexión es siempre la misma para tu proyecto, salvo el usuario y la contraseña. Te pedirá la contraseña de forma segura cada vez que te conectes. ⚠️ Guarda bien tu contraseña, ya que no se muestra ni se almacena en la URI por motivos de seguridad.

💻 Instalación directa según tu sistema

  • 🪟 Windows:
    1. Entra en https://www.mongodb.com/try/download/shell.
    2. Selecciona Windows (64-bit) y descarga el archivo .msi.
    3. Ejecuta el instalador y sigue estos pasos:
      • Pulsa Next → acepta la licencia.
      • Elige Complete installation.
      • Deja marcada la opción Add mongosh to PATH (importante).
      • Haz clic en Install y luego en Finish.
    4. Cierra y vuelve a abrir tu terminal (PowerShell o Windows Terminal).
    5. Verifica la instalación:
    mongosh --version

    Deberías ver algo como 2.x.x.

  • 🍏 macOS: puedes instalarlo fácilmente con Homebrew:
    • brew install mongosh
  • 🐧 Linux (Debian/Ubuntu): instala desde los repos oficiales o con:
    • sudo apt install mongosh
✅ Prueba rápida: abre una nueva terminal y escribe mongosh. Si ves un prompt test>, ¡ya estás dentro de la consola! Sal con exit.
🔐 Resumen:
  • Identifícate en Atlas y usa la opción Connect → Connect with MongoDB Shell.
  • Copia el comando de conexión que te da Atlas (URI con tu clúster y usuario).
  • Guarda la contraseña en un lugar seguro (no se muestra ni se guarda en texto plano).
  • Comprueba que mongosh está instalado correctamente con mongosh --version.

2.2 Conectarte a tu base de datos Atlas (desde Windows)

Una vez instalado mongosh, el siguiente paso es conectarte a tu base de datos en la nube (Atlas). Para ello, usarás la cadena de conexión URI que te da Atlas y tu nombre de usuario.

  1. Abre tu terminal (PowerShell o Windows Terminal).
  2. En MongoDB Atlas, entra en tu Cluster → pulsa Connect → elige “Connect with the MongoDB Shell”.
  3. Copia la cadena de conexión que se muestra, parecida a esta: 
    mongosh "mongodb+srv://<TU_CLUSTER>.mongodb.net/tienda" --username "<TU_USUARIO>"
  4. Pega el comando en tu terminal y pulsa Enter. MongoDB te pedirá la contraseña del usuario (no se muestra al escribir por seguridad).
💡 Ejemplo completo: 
mongosh "mongodb+srv://cluster0.xxxxx.mongodb.net/tienda" --username alumno

Cuando te pida la contraseña, escríbela y pulsa Enter.

📺 Resultado esperado

Si todo ha ido bien, verás algo parecido a esto:

Current Mongosh Log ID: 6738f8d3...
Connecting to:          mongodb+srv://cluster0.xxxxx.mongodb.net/tienda
Using MongoDB:          7.0.5
Using Mongosh:          2.2.10

For mongosh info see: https://docs.mongodb.com/mongodb-shell/

Atlas atlas-xxxxxx-shard-0 [primary] tienda>

El prompt final (por ejemplo tienda>) indica que ya estás dentro de tu base de datos en Atlas y puedes empezar a ejecutar comandos.

✅ Comprobación rápida

// Comprueba en qué base estás
db
// Muestra las bases de datos existentes
show databases

// Muestra las colecciones existentes
show collections

// Crea una nueva base si lo deseas
use tienda

// Inserta un documento de prueba
db.productos.insertOne({ nombre: "Prueba Atlas", precio: 10.99, activo: true })

// Comprueba que se ha guardado
db.productos.find()

Si ves el documento insertado, ¡felicidades! Ya estás trabajando directamente sobre tu base de datos Atlas desde la consola de Windows 🎉

⚠️ Seguridad: Nunca compartas tu contraseña ni publiques tu URI completa. Usa variables de entorno si compartes el proyecto con otros compañeros o subes el código a GitHub.

2.2 Conexión (pide contraseña)

Ejecuta en tu terminal; mongosh pedirá la contraseña de forma segura.

mongosh "mongodb+srv://<NOMBRE_CLUSTER>.mongodb.net/tienda" \
  --username "<DB_USERNAME>"

Comprobar conexión y seleccionar base

// Si no pusiste la DB en la URL, selecciona aquí:
use tienda

// Ver colecciones
show collections

2.4 Solución de errores comunes de conexión

Si al conectar con Atlas te aparece un error, revisa primero este checklist rápido:

  • ¿El usuario y la contraseña son correctos? (Database Access)
  • ¿Tu IP está permitida en Network Access? (o 0.0.0.0/0 en desarrollo)
  • ¿El cluster está Running? (no pausado)
  • ¿La URI tiene el formato mongodb+srv:// correcto?
  • ¿Estás usando mongosh actualizado? mongosh --version

❌ MongoServerError: bad auth / Authentication failed

Causa: usuario o contraseña incorrectos, o el usuario no tiene permisos en esa base (authSource incorrecto).

Solución:

  • Resetea la contraseña del usuario en Database Access.
  • Conéctate así para que mongosh pida la contraseña: 
    mongosh "mongodb+srv://<CLUSTER>.mongodb.net/tienda" --username "<DB_USERNAME>"
  • Si tu usuario solo existe en una DB concreta, añade ?authSource=tu_db: 
    mongodb+srv://<CLUSTER>.mongodb.net/tienda?authSource=tu_db

🔒 not authorized on <db> to execute command

Causa: el usuario no tiene rol para esa operación/base.

Solución:

  • En Database Access, edita el usuario y dale un rol con escritura (p. ej. Read and write to any database en desarrollo).
  • Comprueba que estás en la base correcta: 
    db   // muestra base actual
use tienda

🌐 IP not allowed / connection timed out

Causa: tu IP no está permitida o hay bloqueo de red.

Solución:

  • En Network Access añade tu IP actual o 0.0.0.0/0 (solo desarrollo).
  • Verifica que no haya proxy/cortafuegos corporativo bloqueando la salida TLS (puerto 27017).

🧩 MongoParseError: Invalid connection string

Causa: URI mal escrita (tildes, espacios, parámetros mal formados).

Solución:

  • Usa la URI que da Atlas en Connect → Connect with the MongoDB Shell.
  • Ejemplo válido: 
    mongosh "mongodb+srv://<CLUSTER>.mongodb.net/tienda" --username "<USER>"

🔑 Contraseña con caracteres especiales

Causa: si pones la contraseña dentro de la URI y tiene @, #, :, etc., rompe la URL.

Solución:

  • Mejor no incluir la contraseña en la URI: deja que mongosh la pida.
  • O codifica la contraseña (URL encode). Ej.: @ → %40.

🛰️ Fallo DNS SRV / TLS handshake failed

Causa: DNS del sistema no resuelve el registro SRV o inspección SSL/TLS en la red.

Solución:

  • Prueba en otra red o con DNS públicos (8.8.8.8 / 1.1.1.1).
  • Actualiza mongosh y SO; evita proxys que intercepten TLS.

🧪 Comprobaciones rápidas en consola

// Ver base actual y colecciones
db
show collections

// Probar un insert mínimo
db.test_conexion.insertOne({ ok: true, fecha: new Date() })
db.test_conexion.find().limit(1)
Modo detallado (logs): añade --verbose para más pistas:
mongosh --verbose "mongodb+srv://<CLUSTER>.mongodb.net/tienda" --username "<USER>"

Si nada de esto funciona, revisa en Atlas: Clusters → Metrics (estado), Activity Feed (eventos), y confirma que el nombre del cluster y la base en tu URI son correctos.

2.5 Cerrar sesión y desinstalar mongosh

Cuando termines de trabajar con tu base de datos o quieras liberar espacio en tu equipo, puedes desconectarte y eliminar la shell de forma segura.

🔌 Desconectarte de la sesión actual

Si estás dentro de mongosh (verás algo como tienda> o test>), escribe cualquiera de los siguientes comandos:

exit

O simplemente presiona Ctrl + D. Verás el mensaje:

Bye!

Esto cierra la sesión y desconecta de tu base de datos (Atlas o local). No borra nada de tus datos, solo finaliza la conexión activa.

🧹 Desinstalar mongosh del sistema

Según el método de instalación, usa la opción correspondiente:

🪟 Windows
  • Si lo instalaste con el instalador .msi:
    1. Abre Inicio → Configuración → Aplicaciones → Aplicaciones instaladas.
    2. Busca MongoDB Shell (mongosh).
    3. Pulsa Desinstalar y confirma.
  • Si lo instalaste con Winget: 
    winget uninstall MongoDB.Shell
  • Si lo instalaste con Chocolatey: 
    choco uninstall mongosh -y
  • Ruta típica (por si quieres borrar manualmente): C:\Program Files\MongoDB\mongosh\
🍎 macOS

Si lo instalaste con Homebrew:

brew uninstall mongosh

Para eliminar también configuraciones:

rm -rf ~/.mongodb/mongosh
🐧 Linux (Debian/Ubuntu)

Desinstala con:

sudo apt remove mongosh

O para limpiar por completo:

sudo apt purge mongosh
sudo apt autoremove

Borra configuración si quieres:

rm -rf ~/.mongodb/mongosh

🧭 Resumen rápido

Acción Comando o método
Salir de la sesión exit o Ctrl + D
Desinstalar (Windows) Panel de control → “MongoDB Shell” → Desinstalar
Desinstalar (Winget) winget uninstall MongoDB.Shell
Desinstalar (Chocolatey) choco uninstall mongosh -y
Desinstalar (macOS) brew uninstall mongosh
Desinstalar (Linux) sudo apt remove mongosh
💡 Consejo: Desinstalar mongosh no borra tus bases de datos de Atlas. Tu cluster y los datos siguen seguros en la nube. Solo se elimina la herramienta local de tu ordenador.

🔌 Tipos de conexión con MongoDB Atlas

Atlas ofrece varios métodos de conexión según tu objetivo: practicar comandos, programar con drivers oficiales, usar una interfaz visual o analizar datos. Este resumen te ayuda a elegir el adecuado.

Tipo Para qué sirve Ideal para… Qué obtienes
Drivers (Node.js, Python, Java…) Conectar tu aplicación usando los drivers oficiales. APIs/Backends con Mongoose o drivers nativos. URI mongodb+srv:// para tu .env.
Shell (mongosh) Ejecutar comandos CRUD directamente en consola. Aprendizaje, pruebas rápidas y administración básica. Comando mongosh con usuario/contraseña.
Compass Interfaz gráfica de escritorio para explorar y editar datos. Visualizar colecciones sin escribir comandos. Conexión por URI dentro de la app Compass.
MongoDB for VS Code Extensión que integra Atlas en el editor. Trabajar en VS Code viendo colecciones y ejecutando scripts. Panel de conexión dentro de la extensión.
Atlas SQL Consulta de datos en modo SQL (solo lectura). Dashboards en Excel/Power BI/Tableau y equivalencias SQL. Endpoint SQL y credenciales para herramientas BI.

1) Drivers → Conectar una app (p. ej., Node.js + Mongoose)

  1. Atlas → Connect → Drivers → Driver: Node.js.
  2. Copia tu URI y guárdalo en .env:
# .env
MONGO_URI=mongodb+srv://app_user:TUPASS@<cluster>.mongodb.net/mi_tienda

Conecta con Mongoose:

// src/db.js
import mongoose from "mongoose";
await mongoose.connect(process.env.MONGO_URI);
console.log("✅ Conectado a Atlas");
Nota: La URI no cambia cada vez; reutilízala salvo que cambies usuario, contraseña, clúster o reglas de red.

2) Shell (mongosh) → Practicar comandos

  1. Instala mongosh (desde el asistente de Connect → Shell).
  2. Conéctate desde PowerShell/Terminal:
mongosh "mongodb+srv://<cluster>.mongodb.net/" --apiVersion 1 --username app_user
# luego escribe tu contraseña
show dbs
use mi_tienda
db.productos.find()
Tip: Crea un alias en PowerShell para no pegar la cadena cada vez.

3) Compass → Interfaz visual

Descarga Compass, abre “New Connection” y pega la URI mongodb+srv://…. Podrás ver colecciones, filtrar, crear índices y hacer agregaciones con asistentes.

4) MongoDB for VS Code → Todo en el editor

  1. Instala la extensión MongoDB for VS Code.
  2. Conéctate a Atlas con tu URI y navega colecciones desde la barra lateral.

5) Atlas SQL → Análisis en herramientas BI

Activa Atlas SQL para exponer colecciones como tablas virtuales (solo lectura) y conéctalas a Excel, Power BI o Tableau para informes.

Seguridad: Usa usuarios específicos de BD (no tu login de Atlas), guarda el URI en variables de entorno, limita IPs permitidas y rota contraseñas si las compartiste por error.
