Colección Pedidos

En esta lección aprenderás a crear la colección pedidos, que conecta clientes y productos, aplicando relaciones uno-a-muchos y usando populate() en cascada.

🎯 Objetivos de la lección

  • Entender cómo modelar un pedido con varios productos y un cliente asociado.
  • Aprender a usar ObjectId en arreglos de referencias.
  • Usar populate() en cascada para mostrar cliente + productos en un pedido.
  • Crear ejemplos funcionales con Thunder Client.

🧩 Cómo se relacionan las colecciones

Un pedido se compone de tres partes esenciales:

  • 🧑‍💼 Cliente → quién hace el pedido.
  • 🛒 Productos → qué artículos incluye.
  • 📅 Datos del pedido → fecha, total, estado.
// Relación conceptual
Pedido {
  cliente: ObjectId(Cliente),
  productos: [ ObjectId(Producto), ObjectId(Producto) ],
  fecha: Date,
  total: Number
}

Así conseguimos que un pedido pueda tener varios productos y un cliente único asociado.

🧱 Paso 1 — Crear los modelos

📄 src/models/Cliente.js

import mongoose from "mongoose";

const clienteSchema = new mongoose.Schema({
  nombre: { type: String, required: true },
  email: { type: String, required: true, unique: true },
  telefono: { type: String }
}, { timestamps: true });

const Cliente = mongoose.model("Cliente", clienteSchema);
export default Cliente;

📄 src/models/Pedido.js

import mongoose from "mongoose";

const pedidoSchema = new mongoose.Schema({
  cliente: { type: mongoose.Schema.Types.ObjectId, ref: "Cliente", required: true },
  productos: [{ type: mongoose.Schema.Types.ObjectId, ref: "Producto", required: true }],
  fecha: { type: Date, default: Date.now },
  total: { type: Number, min: 0 }
}, { timestamps: true });

const Pedido = mongoose.model("Pedido", pedidoSchema);
export default Pedido;
Observa: el campo productos es un array de referencias a la colección productos. Esto permite que un pedido tenga varios artículos.

⚙️ Paso 2 — Controlador de pedidos

El controlador gestionará la creación y lectura de pedidos, usando populate() para mostrar datos relacionados.

// 📄 src/controllers/pedidosController.js
import Pedido from "../models/Pedido.js";
import Cliente from "../models/Cliente.js";
import Producto from "../models/Producto.js";

class PedidosController {

  // Crear un pedido
  async crearPedido(req, res) {
    try {
      const { cliente, productos, total } = req.body;
      if (!cliente || !productos || productos.length === 0) {
        return res.status(400).json({ status: "error", message: "Cliente y productos son obligatorios" });
      }
      const nuevo = await Pedido.create({ cliente, productos, total });
      res.status(201).json({ status: "ok", data: nuevo });
    } catch (e) {
      console.error(e);
      res.status(500).json({ status: "error", message: "Error al crear pedido" });
    }
  }

  // Listar todos los pedidos con cliente y productos poblados
  async listarPedidos(req, res) {
    try {
      const pedidos = await Pedido.find()
        .populate("cliente", "nombre email")
        .populate("productos", "nombre precio");
      res.json({ status: "ok", total: pedidos.length, data: pedidos });
    } catch (e) {
      console.error(e);
      res.status(500).json({ status: "error", message: "Error al listar pedidos" });
    }
  }

  // Obtener un pedido por ID
  async obtenerPedido(req, res) {
    try {
      const pedido = await Pedido.findById(req.params.id)
        .populate("cliente", "nombre email")
        .populate("productos", "nombre precio");
      if (!pedido) return res.status(404).json({ status: "error", message: "Pedido no encontrado" });
      res.json({ status: "ok", data: pedido });
    } catch (e) {
      res.status(400).json({ status: "error", message: "ID inválido" });
    }
  }
}

export default new PedidosController();
Explicación:
  • populate("cliente") sustituye el ID del cliente por su nombre y email.
  • populate("productos") hace lo mismo para los productos del pedido.
  • En el resultado final se muestran datos reales, no solo IDs.

🌐 Paso 3 — Rutas para pedidos

// 📄 src/routes/pedidos.routes.js
import { Router } from "express";
import ctrl from "../controllers/pedidosController.js";
const route = Router();

route.post("/", ctrl.crearPedido);
route.get("/", ctrl.listarPedidos);
route.get("/:id", ctrl.obtenerPedido);

export default route;

Y en tu server.js debes montar el router:

import pedidosRoutes from "./routes/pedidos.routes.js";
app.use("/api/pedidos", pedidosRoutes);

📘 Resumen final

  • Un pedido se relaciona con un cliente (uno-a-muchos).
  • Y con muchos productos (muchos-a-muchos vía array).
  • Gracias a populate(), podemos mostrar toda la información combinada.
  • Las relaciones múltiples permiten crear modelos de negocio completos (tienda, reservas, envíos, etc.).

Ejercicio final: crea un pedido nuevo y muestra en la respuesta el nombre del cliente y los productos comprados con sus precios. Luego calcula el total automáticamente en el backend.
