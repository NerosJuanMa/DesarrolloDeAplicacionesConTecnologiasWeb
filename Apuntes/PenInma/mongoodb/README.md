## 📋 Información del Curso

**🎯 Objetivo:** Migrar de trabajar con archivos JSON a bases de datos NoSQL (MongoDB) y relacionales (MySQL)

**👥 Audiencia:** Desarrolladores que ya han trabajado con CRUD básico usando archivos JSON

**⏱️ Duración:** 3 días intensivos

**📊 Proyecto Final:** Sistema completo de gestión de canciones con ambas bases de datos

## 📚 Estructura del Curso

### 📅 DÍA 1: Introducción a MongoDB
- 🏁 **Módulo 1:** Comparación JSON vs MongoDB
- 🔧 **Módulo 2:** Instalación y configuración
- 📊 **Módulo 3:** MongoDB Compass y Shell
- 🎵 **Módulo 4:** Primera migración - Canciones JSON → MongoDB

### 📅 DÍA 2: CRUD Avanzado en MongoDB
- 📝 **Módulo 1:** Operaciones CRUD completas
- 🔍 **Módulo 2:** Consultas avanzadas y agregaciones
- 🔗 **Módulo 3:** Relaciones y referencias
- 🎨 **Módulo 4:** Interfaz web con MongoDB

### 📅 DÍA 3: Migración a MySQL
- 🔄 **Módulo 1:** MongoDB vs MySQL - Comparativa
- 🏗️ **Módulo 2:** Diseño de esquemas relacionales
- 📤 **Módulo 3:** Migración de datos
- 🎯 **Módulo 4:** Proyecto final integrado

## 🛠️ Requisitos Previos

- ✅ Conocimientos básicos de JavaScript
- ✅ Experiencia con CRUD usando archivos JSON
- ✅ Conceptos básicos de APIs REST
- ✅ Node.js instalado

## 📦 Tecnologías que Utilizaremos

### 🍃 NoSQL (MongoDB)
- MongoDB Community Server
- MongoDB Compass (GUI)
- Mongoose (ODM para Node.js)

### 🗄️ SQL (MySQL)
- MySQL Server
- MySQL Workbench
- Sequelize (ORM para Node.js)

### 🌐 Desarrollo Web
- Node.js + Express
- HTML/CSS/JavaScript
- Postman para testing

## 🎯 Proyecto Central: Sistema de Gestión de Canciones

Trabajaremos con un sistema que gestiona:
- 🎵 **Canciones** (título, artista, duración, género)
- 👤 **Artistas** (nombre, biografía, país)
- 💿 **Álbumes** (título, año, canciones)
- ⭐ **Reseñas** (puntuación, comentario, usuario)

## 📈 Progresión del Aprendizaje

```
📁 Archivo JSON
    ↓
🍃 MongoDB (NoSQL)
    ↓
🗄️ MySQL (SQL)
    ↓
🔗 Sistema Híbrido
```

## 🏆 Objetivos de Aprendizaje

Al finalizar este curso, serás capaz de:

- ✅ Migrar datos desde archivos JSON a MongoDB
- ✅ Realizar operaciones CRUD avanzadas en MongoDB
- ✅ Diseñar esquemas relacionales en MySQL
- ✅ Migrar datos entre MongoDB y MySQL
- ✅ Crear aplicaciones web conectadas a ambas bases de datos
- ✅ Decidir cuándo usar NoSQL vs SQL
