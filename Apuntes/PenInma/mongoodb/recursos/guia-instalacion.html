🛠️ Guía de Instalación

Todo lo necesario para el curso de MongoDB de 3 días

📊 Progreso de Instalación

0% completado

📋 Lista de Verificación Previa

🚀 Paso 1: Instalación de Node.js

▼

📥 Descargar Node.js

Node.js es esencial para ejecutar JavaScript en el servidor y manejar las dependencias del proyecto.

💡 Recomendación: Siempre descarga la versión LTS (Long Term Support) para mayor estabilidad.
📥 Descargar Node.js LTS

⚙️ Proceso de Instalación

  1. Ejecutar el instalador .msi descargado
  2. Seguir el asistente de instalación (configuración por defecto está bien)
  3. ✅ Asegurarse de que "Add to PATH" esté marcado
  4. Reiniciar el sistema si es necesario

🔍 Verificar Instalación

# Abrir Command Prompt y verificar node --version npm --version # Resultado esperado: v18.17.0 (o superior) 9.6.7 (o superior)

🍃 Paso 2: Instalación de MongoDB

▼

📥 Descargar MongoDB Community Server

MongoDB Community Server es la versión gratuita y completa de MongoDB.

⚠️ Importante: Asegúrate de seleccionar la versión correcta para Windows 64-bit.
📥 Descargar MongoDB Community

⚙️ Configuración de Descarga

  • Version: 7.0.x (Current)
  • Platform: Windows
  • Package: msi

🔧 Proceso de Instalación

  1. Ejecutar mongodb-windows-x86_64-7.0.x.msi
  2. Seleccionar "Complete" installation
  3. ✅ "Install MongoDB as a Service"
  4. ✅ "Run service as Network Service user"
  5. ✅ "Install MongoDB Compass" (GUI)
  6. Completar instalación

📁 Crear Directorios de Datos

# Abrir Command Prompt como Administrador mkdir C:\data\db mkdir C:\data\log

🔍 Verificar Instalación

# Verificar MongoDB Server mongod --version # Verificar MongoDB Shell mongosh --version # Verificar servicio net start | findstr MongoDB
Si ves la versión de MongoDB y el servicio está corriendo, ¡la instalación fue exitosa!

🗄️ Paso 3: Instalación de MySQL (Para Día 3)

▼

📥 Descargar MySQL Community Server

MySQL se usará en el Día 3 para la migración y sistemas híbridos.

📥 Descargar MySQL Community

⚙️ Proceso de Instalación

  1. Ejecutar el instalador MSI
  2. Seleccionar "Developer Default"
  3. Configurar Root Password (¡anótala!)
  4. Crear usuario para desarrollo
  5. ✅ Instalar como servicio de Windows

🔍 Verificar MySQL

# Verificar versión mysql --version # Conectar a MySQL mysql -u root -p
💡 Nota: MySQL Workbench se instala automáticamente y te dará una interfaz gráfica similar a MongoDB Compass.

👨‍💻 Paso 4: Editor de Código (Recomendado)

▼

📥 Visual Studio Code

VS Code es el editor recomendado con excelente soporte para MongoDB y desarrollo web.

📥 Descargar VS Code

🔌 Extensiones Recomendadas

# Extensiones esenciales para el curso: - MongoDB for VS Code - MySQL (by Jun Han) - JavaScript (ES6) code snippets - Prettier - Code formatter - GitLens - Thunder Client (para testing APIs)

⚙️ Configuración MongoDB Extension

  1. Instalar "MongoDB for VS Code"
  2. Conectar a mongodb://localhost:27017
  3. Explorar bases de datos desde el panel lateral

📦 Paso 5: Configuración del Proyecto

▼

📁 Crear Carpeta de Trabajo

mkdir C:\curso-mongodb cd C:\curso-mongodb

🌐 Dependencias Globales

# Instalar herramientas globales útiles npm install -g nodemon npm install -g json-server npm install -g http-server

✅ Paso 6: Verificación Final

▼

🧪 Test MongoDB

# Conectar a MongoDB mongosh # Crear base de datos de prueba use testDB db.test.insertOne({nombre: "Curso MongoDB", fecha: new Date()}) db.test.find() # Salir exit

🧪 Test MySQL

# Conectar a MySQL mysql -u root -p # Crear base de datos de prueba CREATE DATABASE testDB; USE testDB; CREATE TABLE test (id INT PRIMARY KEY, nombre VARCHAR(50)); INSERT INTO test VALUES (1, 'Curso MongoDB'); SELECT * FROM test; # Salir exit

🧪 Test Node.js

# Crear archivo de prueba echo console.log("Node.js funcionando!"); > test.js # Ejecutar node test.js # Resultado esperado: Node.js funcionando!
🎉 ¡Perfecto! Si todos los tests funcionan, estás listo para comenzar el curso.

🔧 Solución de Problemas

MongoDB no inicia

# Verificar estado del servicio sc query MongoDB # Iniciar manualmente net start MongoDB

MySQL no conecta

# Verificar servicio MySQL net start | findstr MySQL # Iniciar si está parado net start MySQL80

Node.js no reconocido

1. Reiniciar Command Prompt después de la instalación

2. Verificar que Node.js esté en el PATH

3. Reinstalar Node.js si es necesario
