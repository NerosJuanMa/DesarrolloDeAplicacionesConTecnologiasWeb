📝 Módulo 1: CRUD Completo (9:00 - 10:30)

▼

🔍 Operadores Avanzados

Dominaremos operadores que van más allá de las consultas básicas:

// Operadores de comparación db.canciones.find({duracion: {$gt: 300}}) // mayor que db.canciones.find({año: {$gte: 1970, $lte: 1980}}) // rango // Operadores de array db.canciones.find({genero: {$in: ["Rock", "Pop"]}}) db.canciones.find({tags: {$all: ["clasico", "popular"]}}) // Expresiones regulares db.canciones.find({titulo: {$regex: /queen/i}})

📊 Proyecciones y Ordenamiento

// Seleccionar campos específicos db.canciones.find({}, {titulo: 1, artista: 1, _id: 0}) // Paginación db.canciones.find().skip(10).limit(5) // Ordenamiento avanzado db.canciones.find().sort({genero: 1, año: -1})
💻 Practicar CRUD 📖 Ver Referencia

🔍 Módulo 2: Consultas Avanzadas y Agregaciones (10:30 - 12:00)

▼

🔗 Pipeline de Agregación

El poder real de MongoDB está en sus agregaciones:

// Agrupar por género y contar db.canciones.aggregate([ {$group: {_id: "$genero", total: {$sum: 1}}}, {$sort: {total: -1}} ]) // Calcular estadísticas db.canciones.aggregate([ {$group: { _id: "$genero", promedio_duracion: {$avg: "$duracion"}, cancion_mas_larga: {$max: "$duracion"}, total_reproducciones: {$sum: "$reproducciones"} }} ])

🔎 Búsqueda de Texto Completo

// Crear índice de texto db.canciones.createIndex({titulo: "text", artista: "text"}) // Buscar texto db.canciones.find({$text: {$search: "queen bohemian"}})

🔗 Módulo 3: Relaciones y Referencias (13:00 - 14:30)

▼

📚 Documentos Embebidos vs Referencias

Aprenderemos cuándo usar cada estrategia:

// Documento embebido (datos relacionados pequeños) { titulo: "Bohemian Rhapsody", artista: { nombre: "Queen", pais: "Reino Unido" } } // Referencias (datos relacionados grandes) { titulo: "Bohemian Rhapsody", artista_id: ObjectId("...") }

🦫 Mongoose y Populate

// Esquema con referencias const cancionSchema = { titulo: String, artista: {type: ObjectId, ref: 'Artista'} } // Populate para traer datos relacionados Cancion.find().populate('artista')
