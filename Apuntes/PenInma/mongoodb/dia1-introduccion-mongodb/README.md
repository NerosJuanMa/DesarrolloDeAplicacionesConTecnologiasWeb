## 🎯 Objetivos del Día
- Entender las diferencias entre archivos JSON y MongoDB
- Instalar y configurar MongoDB
- Realizar la primera migración de datos
- Crear operaciones CRUD básicas

## 📚 Módulos del Día

### 🏁 Módulo 1: JSON vs MongoDB (9:00 - 10:30)
- **Teoría:** Limitaciones de los archivos JSON
- **Práctica:** Análisis de nuestro archivo de canciones
- **Demo:** Ventajas de MongoDB

### 🔧 Módulo 2: Instalación y Configuración (10:30 - 12:00)
- **Instalación:** MongoDB Community Server
- **Configuración:** Variables de entorno
- **Herramientas:** MongoDB Compass

### 📊 Módulo 3: MongoDB Compass y Shell (13:00 - 14:30)
- **GUI:** Navegando con Compass
- **CLI:** Comandos básicos del shell
- **Práctica:** Creando nuestra primera base de datos

### 🎵 Módulo 4: Primera Migración (14:30 - 16:00)
- **Migración:** Del JSON a MongoDB
- **CRUD:** Operaciones básicas
- **Validación:** Verificando la migración
