🏁 Módulo 1: JSON vs MongoDB (9:00 - 10:30)

▼

📖 Teoría: Limitaciones de los archivos JSON

En este módulo exploraremos por qué los archivos JSON, aunque útiles para prototipos, tienen limitaciones importantes:

  • Concurrencia: Múltiples usuarios no pueden modificar el mismo archivo simultáneamente
  • Performance: Leer archivos completos para consultas simples
  • Escalabilidad: Problemas de memoria con archivos grandes
  • Consultas Complejas: Dificultad para filtros y búsquedas avanzadas

🎵 Práctica: Análisis de nuestro archivo de canciones

Trabajaremos con un archivo JSON de ejemplo que contiene información de canciones y identificaremos sus limitaciones.

Dominaremos los comandos básicos del shell:
