Mejor para:

  • Datos estructurados y consistentes
  • Transacciones complejas

  • Aplicaciones empresariales
  • Cumplimiento normativo

🎯 Filosofías de Base de Datos

📄 NoSQL (MongoDB)
  • Esquema flexible: Sin estructura fija
  • Escalabilidad horizontal: Distribuir datos
  • Documentos JSON: Datos naturalmente anidados
  • Eventual consistency: Performance > consistencia
🗄️ SQL (MySQL)
  • Esquema rígido: Estructura definida
  • Escalabilidad vertical: Mejorar hardware
  • Tablas relacionales: Datos normalizados
  • ACID compliance: Consistencia garantizada

📊 Casos de Uso Prácticos

🍃 Usa MongoDB cuando:
  • Los datos cambian frecuentemente de estructura
  • Necesitas análisis en tiempo real
  • Trabajas con datos no estructurados
  • Requieres escalabilidad masiva
🗄️ Usa MySQL cuando:
  • Los datos tienen relaciones complejas
  • Necesitas transacciones garantizadas
  • Trabajas con reportes y análisis
  • Requieres cumplimiento normativo

📋 De Documentos a Tablas

Proceso de normalización desde MongoDB hacia MySQL:

-- Documento MongoDB original { "titulo": "Bohemian Rhapsody", "artista": { "nombre": "Queen", "pais": "Reino Unido" }, "album": { "titulo": "A Night at the Opera", "año": 1975 } } -- Tablas MySQL normalizadas CREATE TABLE artistas ( id INT PRIMARY KEY AUTO_INCREMENT, nombre VARCHAR(100) NOT NULL, pais VARCHAR(50) ); CREATE TABLE albumes ( id INT PRIMARY KEY AUTO_INCREMENT, titulo VARCHAR(150) NOT NULL, año INT, artista_id INT, FOREIGN KEY (artista_id) REFERENCES artistas(id) ); CREATE TABLE canciones ( id INT PRIMARY KEY AUTO_INCREMENT, titulo VARCHAR(150) NOT NULL, duracion INT, album_id INT, FOREIGN KEY (album_id) REFERENCES albumes(id) );

🔗 Tipos de Relaciones

  1. Uno a Uno (1:1): Usuario ↔ Perfil
  2. Uno a Muchos (1:N): Artista → Canciones
  3. Muchos a Muchos (N:M): Canciones ↔ Géneros

🔄 Proceso ETL (Extract, Transform, Load)

1. 📤 EXTRACT (Extraer de MongoDB)
// Extraer datos de MongoDB const canciones = await db.collection('canciones').find({}).toArray(); const artistasUnicos = [...new Set(canciones.map(c => c.artista))];
2. 🔄 TRANSFORM (Transformar datos)
// Transformar estructura const artistas = artistasUnicos.map((nombre, index) => ({ id: index + 1, nombre: nombre, pais: 'Por determinar' })); const cancionesSQL = canciones.map(cancion => ({ titulo: cancion.titulo, duracion: cancion.duracion, artista_id: artistas.find(a => a.nombre === cancion.artista).id }));
3. 📥 LOAD (Cargar en MySQL)
-- Insertar en MySQL INSERT INTO artistas (nombre, pais) VALUES ('Queen', 'Reino Unido'); INSERT INTO canciones (titulo, duracion, artista_id) VALUES ('Bohemian Rhapsody', 355, 1);
