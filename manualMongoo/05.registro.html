Tema 5

Registrarse y empezar a usar MongoDB Atlas

Tu primer contacto con MongoDB en la nube: crear cuenta, base de datos y colección paso a paso.

🏠 Inicio ➡️ Tema 6: Creando colecciones y CRUD

🌍 1️⃣ ¿Qué es MongoDB Atlas?

MongoDB Atlas es la versión en la nube de MongoDB. No necesitas instalar nada en tu ordenador: todo funciona online desde el navegador.

Podrás crear bases de datos, colecciones y documentos en pocos clics y conectarlas fácilmente con tus proyectos Node.js.

🧭 2️⃣ Crear tu cuenta gratuita

  1. Abre la página oficial: 👉 https://www.mongodb.com/atlas
  2. Haz clic en “Try Free” o “Start Free”.
  3. Regístrate con Google o con correo electrónico (elige plan Free Tier).
  4. Completa el formulario inicial. Si pregunta por el uso, elige “Learning” o “Personal”.

💡 Consejo:

Usa tu correo habitual para no perder el acceso. Si usas Google, podrás entrar con un clic. Cuando te pregunte si quieres “Serverless”, elige “No por ahora”.

🧱 3️⃣ Crear tu primer Deployment (Cluster)

  1. En el panel principal, haz clic en “Build a Database”.
  2. Selecciona el plan gratuito Shared (Free).
  3. Proveedor: AWS — Región: Paris (eu-west-3).
  4. Deja activado Automate security setup.
  5. Pulsa “Create Deployment”. Espera 1–2 minutos.

🔐 Seguridad inicial

  • Atlas añadirá automáticamente tu IP actual (para permitir conexiones).
  • Te pedirá crear un usuario de base de datos. Puedes dejar el que te sugiere o usar uno simple como mongoo_user / mongoo123 (solo para prácticas).

Después, haz clic en “Elija un método de conexión”.

🔗 4️⃣ Obtener el URI limpio y configurar variables .env

  1. En la ventana “Elija un método de conexión”, selecciona “Connect your application”.
  2. Elige el controlador Node.js y copia la cadena de conexión.
  3. Te mostrará algo como: 
    mongodb+srv://TU_USUARIO:TU_CONTRASEÑA@TUNOMBRE.lfxkraj.mongodb.net/?appName=TUAPP
  4. Elimina la contraseña (lo que hay después de los dos puntos : hasta el @): 
    mongodb+srv://TU_USUARIO@TUNOMBRE.lfxkraj.mongodb.net/?appName=TUAPP
  5. Copia ese enlace en un archivo llamado .env (sin nombre delante).

📄 Tu archivo .env debe quedar así:

MONGO_URI="mongodb+srv://inmacontreras2709_db_user@ici27.lfxkraj.mongodb.net/mongoo?retryWrites=true&w=majority&appName=ici27"
MONGO_USER="inmacontreras2709_db_user"
MONGO_PASS="TU_CONTRASEÑA_REAL"

⚠️ Importante

  • Atlas solo muestra la contraseña una vez. Cópiala y guárdala.
  • No pongas la contraseña dentro del URI.
  • No subas tu archivo .env a GitHub.

🧩 5️⃣ Crear el archivo .gitignore

Git necesita saber qué archivos no debe subir. Crea un archivo llamado .gitignore en la raíz del proyecto y pega:

node_modules/
.env
.DS_Store
Thumbs.db

Esto evita subir tus contraseñas y dependencias innecesarias.

⚙️ 6️⃣ Crear y probar la conexión con Mongoose

  1. Instala Mongoose: 
    npm install mongoose
  2. Crea server.js con este contenido:
import mongoose from "mongoose";

const uri = process.env.MONGO_URI;
const user = process.env.MONGO_USER;
const pass = process.env.MONGO_PASS;

mongoose.connect(uri, { user, pass })
  .then(() => console.log("✅ Conectado a MongoDB Atlas"))
  .catch(err => console.error("❌ Error de conexión:", err));

▶️ Ejecutar correctamente

En lugar de usar el botón “Run Code” de VS Code (que no carga el archivo .env), abre la terminal y escribe:

node --env-file=.env server.js

Deberías ver:

✅ Conectado a MongoDB Atlas

💡 Consejo:

Para no tener que escribir el comando completo cada vez, abre tu package.json y agrega:

"scripts": {
  "start": "node --env-file=.env server.js"
}

Ahora podrás ejecutar el servidor con:

npm start

🧪 7️⃣ Añadir un servidor Express para probar

Para comprobar que tu servidor responde correctamente, instala Express:

npm install express

Y modifica tu server.js así:

import express from "express";
import mongoose from "mongoose";

const app = express();
app.use(express.json());

const uri = process.env.MONGO_URI;
const user = process.env.MONGO_USER;
const pass = process.env.MONGO_PASS;

mongoose.connect(uri, { user, pass })
  .then(() => console.log("✅ Conectado a MongoDB Atlas"))
  .catch(err => console.error("❌ Error de conexión:", err));

// Pequeña ruta de prueba
app.get("/", (req, res) => {
  res.json({ mensaje: "Servidor funcionando", productos: [] });
});

const PORT = 3000;
app.listen(PORT, () => {
  console.log(`🚀 Servidor escuchando en http://localhost:${PORT}`);
});

Ejecuta:

npm start

Abre tu navegador en http://localhost:3000 y deberías ver:

{
  "mensaje": "Servidor funcionando",
  "productos": []
}

🎉 ¡Felicidades! Tu servidor Node, Express y MongoDB Atlas están conectados correctamente.
