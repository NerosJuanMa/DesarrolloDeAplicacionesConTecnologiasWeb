¿Qué es este manual?

Es una introducción a “Mongo” (base de datos no relacional orientada a documentos). El objetivo es que conozcas las bases de las dos bases de datos más usadas en desarrollo web:MySQLcomo base de datos relacional y Mongo como base de datos no relacional.

Objetivos de aprendizaje

  • Entender el concepto de base de datos y diferenciar relacional vs. no relacional.
  • Conocer “Mongoo”: documentos, colecciones y operaciones básicas (CRUD).
  • Identificar tipos de datos más comunes y su equivalencia aproximada en MySQL.
  • Instalar y preparar el entorno en VS Code para trabajar con datos.
  • Construir un CRUD sencillo con “Mongoo” y analizar cómo se haría el mismo ejercicio en MySQL.
  • Salir con un mapa mental claro para continuar con MySQL sin perderte.

Metodología

Seguiremos un enfoque progresivo: primero teoría clara con ejemplos didacticos y progresivos; después instalación y, por último, un mini‑proyecto CRUD. En cada lección añadiremos notas que indiquen cómo se haría la misma tarea en MySQL para facilitar la transición. Finalmente haremos un proyecto completo
