Tema 7

CRUD en el Mongo Shell (Caparazón)

Conéctate a tu cluster, inserta, consulta, actualiza y borra datos desde el Shell. El primer paso hacia el uso profesional de Mongoose.

💡 Introducción

En este tema aprenderás a usar el Mongo Shell (también llamado mongosh o Caparazón), la herramienta de línea de comandos oficial de MongoDB. Con ella puedes practicar las operaciones CRUD: Create, Read, Update y Delete, directamente sobre tu base de datos Atlas.

Este método es ideal para estudiantes y administradores, porque te permite manipular los datos sin necesidad de un programa. En el siguiente tema harás exactamente lo mismo, pero de forma profesional con Node.js y Mongoose.

🧩 1️⃣ Acceder al Mongo Shell (Caparazón)

💻 ¿Qué es el Shell?

El Shell es una consola que permite escribir comandos para comunicarse directamente con tu base de datos. Es el equivalente a una terminal, pero especializada en MongoDB.

☁️ Acceso desde Atlas

  1. Entra en tu Cluster dentro de Atlas (por ejemplo: ici27).
  2. Haz clic en el botón “Conectar”.
  3. Selecciona la opción “Caparazón” (Shell).

Atlas te mostrará un comando parecido a este:

mongosh "mongodb+srv://ici27.lfxkraj.mongodb.net/" --apiVersion 1 --username inmacontreras2709_db_user

⚙️ Pasos para conectarte

  1. Abre tu terminal (CMD o PowerShell en Windows).
  2. Pega el comando anterior.
  3. Cuando te lo pida, escribe la contraseña de tu usuario Atlas (no se muestra mientras escribes).

Si ves el mensaje de bienvenida y algo como Atlas [primary] mi_tienda>, ¡ya estás dentro del Shell!

🏗️ 2️⃣ Crear la Base de Datos y la Colección

MongoDB crea las bases de datos y colecciones automáticamente cuando insertas tu primer documento. Sin embargo, puedes crearlas manualmente desde Atlas o con el comando use.

🛠️ Opción práctica: crear base y colección desde Atlas

  1. Abre Data Explorer en Atlas.
  2. Pulsa “+ Create Database”.
  3. Introduce:
    • Base de datos: mi_tienda
    • Colección: productos
  4. Haz clic en Crear.

💻 Opción con comandos (en el Shell)

// Cambiar a la base de datos (si no existe, se crea)
use mi_tienda
// Inserta tu primer documento (creará la colección automáticamente)
db.productos.insertOne({
  nombre: "Taza Code Master",
  precio: 12.5,
  stock: 50,
  categoria: "accesorios",
  activo: true
})

✔️ Con esto ya tienes la base mi_tienda y la colección productos.

📥 3️⃣ Insertar Datos (CREATE)

Insertar múltiples documentos

Usa insertMany() para crear varios registros a la vez:

db.productos.insertMany([
  { nombre: "Taza Code Master", precio: 12.5, stock: 50, categoria: "accesorios", activo: true },
  { nombre: "Sudadera Node", precio: 55.0, stock: 10, categoria: "ropa", activo: true },
  { nombre: "Libreta Desarrollo", precio: 4.99, stock: 120, categoria: "papeleria", activo: false }
])

💡 MongoDB crea automáticamente la colección si no existía. No necesitas un comando “create table” como en SQL.

🔍 4️⃣ Leer los Datos (READ)

La lectura o consulta de documentos en MongoDB se realiza con el método find(). Este método te permite ver toda la información guardada en una colección o aplicar filtros y formatos para obtener solo lo que necesitas.

📘 Sintaxis general del método find()

El método find() se usa para leer los documentos guardados en una colección. Tiene hasta dos parámetros principales y, en casos especiales, un tercero para opciones avanzadas.

db.coleccion.find(filtro, proyeccion, opciones)
  • filtro → indica qué documentos quieres buscar. Ejemplo: { categoria: "ropa" } o { precio: { $gt: 50 } }.
  • proyección → indica qué campos mostrar u ocultar. Ejemplo: { nombre: 1, precio: 1 }.
  • opciones (opcional) → controla detalles como el orden o el número de resultados Ejemplo: { sort: { precio: -1 }, limit: 5 }.

📎 Si no pasas ningún parámetro, MongoDB mostrará todos los documentos con todos sus campos. Por defecto, siempre muestra también el campo _id, a menos que tú lo ocultes explícitamente con _id: 0.

🧩 Ejemplos prácticos

// 0️⃣ Sin parámetros → muestra TODO (incluye _id)
db.productos.find()

// 1️⃣ Solo filtro → muestra los productos de la categoría "ropa"
db.productos.find({ categoria: "ropa" })

// 2️⃣ Solo proyección → se puede usar dejando el filtro vacío {}
// Muestra todos los productos pero solo los campos nombre y precio
db.productos.find({}, { nombre: 1, precio: 1 })

// 2️⃣b Filtro + proyección → busca y muestra solo ciertos campos
// Filtro: productos con stock mayor a 10
// Proyección: muestra solo nombre, stock y oculta el _id
db.productos.find({ stock: { $gt: 10 } }, { nombre: 1, stock: 1, _id: 0 })

// 3️⃣ Con opciones → por ejemplo, limitar y ordenar
// Busca productos activos, muestra nombre y precio,
// ordena de mayor a menor precio y limita a 3 resultados
db.productos.find(
  { activo: true },
  { nombre: 1, precio: 1, _id: 0 },
  { sort: { precio: -1 }, limit: 3 }
)

// 🔎 Formatear el resultado en consola para mejor lectura
db.productos.find().pretty()

🧠 Resumen rápido:

  • Si no pones parámetros → muestra todo.
  • El campo _id siempre se incluye, salvo que pongas _id: 0 en la proyección.
  • El primer parámetro es el filtro, el segundo la proyección, y el tercero las opciones.
  • .pretty() solo mejora la presentación en consola, no cambia los datos.

💡 Ejemplo completo y comentado

// Buscar productos activos y caros
db.productos.find(
  { activo: true, precio: { $gt: 50 } },      // Filtro
  { nombre: 1, precio: 1, stock: 1, _id: 0 }, // Proyección
  { sort: { precio: -1 } }                    // Opciones (orden descendente)
)

🔍 Este comando mostrará solo los productos activos con precio mayor que 50, ordenados de mayor a menor, mostrando únicamente el nombre, precio y stock (sin _id).

🧠 Recuerda: en la proyección 1 significa “mostrar” y 0 significa “ocultar”.
Por eso { nombre: 1, precio: 1, _id: 0 } muestra solo nombre y precio, ocultando el _id.

📋 Resumen visual de usos de find()

# Parámetros Qué hace Ejemplo Resultado esperado
0 Muestra todos los documentos y todos los campos (incluye _id). db.productos.find() Todos los productos completos.
1 Usa un filtro para seleccionar qué documentos ver. db.productos.find({ categoria: "ropa" }) Solo productos donde la categoría sea “ropa”.
2 Usa filtro + proyección para decidir qué documentos y qué campos mostrar. db.productos.find({ activo: true }, { nombre: 1, precio: 1, _id: 0 }) Productos activos, mostrando solo nombre y precio, sin _id.
3 Usa filtro + proyección + opciones (ordenar, limitar, etc.). db.productos.find({}, { nombre: 1 }, { sort: { precio: -1 }, limit: 3 }) Muestra los 3 productos más caros, solo con el campo nombre.

💡 Consejo del profesor: En la práctica profesional, casi siempre usarás dos parámetros (filtro y proyección). El tercero (opciones) se usa en casos más avanzados, como ordenaciones, límites o paginación.

🔍 Ejemplo avanzado con operadores de comparación

MongoDB permite realizar búsquedas más potentes usando operadores que comienzan con el signo $. Los más comunes son:

  • $gt → mayor que (greater than)
  • $lt → menor que (less than)
  • $gte → mayor o igual que
  • $lte → menor o igual que
  • $eq → igual que
  • $ne → distinto de

Veamos un ejemplo práctico: buscar productos con precio mayor que 50 y stock menor que 20 (usando $gt y $lt):

db.productos.find({
  precio: { $gt: 50 },
  stock: { $lt: 20 }
}).pretty()

Este filtro busca todos los productos cuyo precio sea superior a 50 y tengan menos de 20 unidades en stock.

Resultado esperado: la Sudadera Node, porque cumple ambas condiciones (precio: 55.0 y stock: 15).

💡 Consejo profesional

Para hacer consultas más claras, puedes combinar filtros y proyecciones al mismo tiempo. Por ejemplo, para mostrar solo el nombre y el precio de los productos caros:

db.productos.find(
  { precio: { $gt: 50 } },            // Filtro
  { nombre: 1, precio: 1, _id: 0 }    // Proyección
)

Esto mostrará solo el nombre y el precio de los productos que cuestan más de 50, sin mostrar los demás campos.

✔️ En resumen:

  • find() → sirve para leer documentos de una colección.
  • Primer parámetro → qué documentos quieres (filtro).
  • Segundo parámetro → qué campos mostrar (proyección).
  • .pretty() → solo mejora la legibilidad en la consola, no cambia los datos.

🔢 Operadores de comparación en MongoDB

MongoDB permite realizar búsquedas muy precisas mediante operadores de comparación. Estos operadores siempre comienzan con el símbolo $ y se colocan dentro del filtro del método find().

📘 Sintaxis general

db.coleccion.find({ campo: { operador: valor } })

Por ejemplo, si quieres buscar los productos cuyo precio sea mayor que 50:

db.productos.find({ precio: { $gt: 50 } })

📊 Tabla de operadores más usados

Operador Significado Ejemplo Qué hace
$eq Igual a { precio: { $eq: 10 } } Devuelve documentos donde el precio sea exactamente 10
$ne Distinto de { categoria: { $ne: "ropa" } } Muestra productos que no sean de ropa
$gt Mayor que { precio: { $gt: 50 } } Encuentra los productos con precio superior a 50
$gte Mayor o igual que { stock: { $gte: 100 } } Busca productos con 100 unidades o más
$lt Menor que { precio: { $lt: 20 } } Muestra productos cuyo precio sea menor que 20
$lte Menor o igual que { stock: { $lte: 5 } } Devuelve productos con 5 unidades o menos

🧠 Ejemplo práctico combinado

Buscar productos con precio mayor que 50 y stock menor que 20 (consulta AND implícita):

db.productos.find({
  precio: { $gt: 50 },
  stock: { $lt: 20 }
}).pretty()

Esto devolverá productos que cumplan ambas condiciones simultáneamente. En nuestro caso, la “Sudadera Node” coincide porque tiene un precio de 55 y un stock de 15.

✔️ Consejo: Puedes combinar los operadores con $and o $or para consultas más complejas:

// Buscar productos caros o sin stock
db.productos.find({
  $or: [
    { precio: { $gt: 50 } },
    { stock: { $lte: 0 } }
  ]
})

Este ejemplo devuelve todos los productos que cuestan más de 50 o no tienen stock.

💬 En resumen:
  • El primer parámetro de find() define las condiciones de búsqueda.
  • Los operadores comienzan con $ y permiten filtrar por rangos o comparaciones.
  • Puedes combinarlos para crear consultas poderosas y precisas.

✏️ 5️⃣ Actualizar Datos (UPDATE)

La operación UPDATE se usa para modificar documentos existentes en una colección. Puedes cambiar uno solo (updateOne()) o varios a la vez (updateMany()).

La sintaxis general es:

db.coleccion.updateOne(filtro, actualizacion)
db.coleccion.updateMany(filtro, actualizacion)
  • filtro → indica qué documento(s) quieres modificar.
  • actualización → usa operadores como $set o $inc para definir qué cambiar.

📘 Operadores más usados en UPDATE

Operador Significado Ejemplo Resultado
$set Cambia el valor de un campo (o lo crea si no existe). { $set: { precio: 14.99 } } Actualiza el campo precio a 14.99.
$inc Incrementa o decrementa un número. { $inc: { stock: -2 } } Resta 2 unidades al campo stock.
$unset Elimina un campo del documento. { $unset: { descripcion: "" } } Borra el campo descripcion.
$rename Cambia el nombre de un campo. { $rename: { precio: "coste" } } Renombra el campo precio a coste.
$mul Multiplica un valor numérico. { $mul: { precio: 1.1 } } Aumenta el precio un 10 % (× 1.1).
$currentDate Actualiza un campo con la fecha actual. { $currentDate: { ultimaModificacion: true } } Guarda la fecha del último cambio.

🧩 Ejemplos prácticos

// 1️⃣ Cambiar el precio de la Taza
db.productos.updateOne(
  { nombre: "Taza Code Master" },
  { $set: { precio: 14.99 } }
)

// 2️⃣ Aumentar el stock de la Sudadera en +5
db.productos.updateOne(
  { nombre: "Sudadera Node" },
  { $inc: { stock: 5 } }
)

// 3️⃣ Reducir el stock de todos los productos activos en -1
db.productos.updateMany(
  { activo: true },
  { $inc: { stock: -1 } }
)

// 4️⃣ Eliminar la descripción de todos los productos inactivos
db.productos.updateMany(
  { activo: false },
  { $unset: { descripcion: "" } }
)

// 5️⃣ Agregar o actualizar la fecha de última modificación
db.productos.updateMany(
  {},
  { $currentDate: { ultimaModificacion: true } }
)

🔍 Comprueba los resultados después de cada actualización:

db.productos.find().pretty()

💡 Consejo:

  • Si el filtro no encuentra coincidencias, no se modifica nada.
  • Los operadores de actualización siempre van dentro de un objeto con $.
  • Puedes combinar varios operadores en la misma instrucción, por ejemplo: 
    { $set: { activo: true }, $currentDate: { ultimaModificacion: true } }

🗑️ 6️⃣ Borrar Datos (DELETE)

La operación DELETE se usa para eliminar documentos de una colección. Es una acción permanente: una vez borrado un documento, no se puede recuperar desde MongoDB (a menos que tengas una copia de seguridad).

Los métodos más comunes son:

db.coleccion.deleteOne(filtro)
db.coleccion.deleteMany(filtro)
  • filtro → indica qué documentos borrar.
  • deleteOne() → elimina solo el primer documento que cumpla el filtro.
  • deleteMany() → elimina todos los documentos que cumplan el filtro.

📘 Métodos de borrado más usados

Método Uso Ejemplo Resultado
deleteOne() Borra solo el primer documento que coincida con el filtro. db.productos.deleteOne({ nombre: "Taza Code Master" }) Elimina la primera “Taza Code Master” que encuentre.
deleteMany() Borra todos los documentos que cumplan el filtro. db.productos.deleteMany({ activo: false }) Elimina todos los productos inactivos.
db.coleccion.drop() Elimina toda la colección completa (como borrar una tabla entera). db.productos.drop() Borra la colección productos y todo su contenido.

🧩 Ejemplos prácticos

// 1️⃣ Borrar un solo producto por nombre
db.productos.deleteOne({ nombre: "Taza Code Master" })

// 2️⃣ Borrar todos los productos inactivos
db.productos.deleteMany({ activo: false })

// 3️⃣ Borrar todos los productos con stock = 0
db.productos.deleteMany({ stock: 0 })

// 4️⃣ Borrar toda la colección (⚠️ elimina todos los datos)
db.productos.drop()

📊 Verificación después del borrado

Para comprobar cuántos documentos siguen existiendo, usa:

db.productos.countDocuments()

O para verificar visualmente:

db.productos.find().pretty()

⚠️ Consejo del profesor:

  • Evita usar deleteMany({}) sin un filtro, porque borrará toda la colección.
  • Siempre revisa antes con find() el conjunto de documentos que vas a eliminar.
  • En proyectos reales, suele usarse un campo lógico activo: false en lugar de eliminar los datos físicamente (borrado lógico).

✅ Si seguiste todos los pasos del CRUD, deberías tener 3 productos activos en tu colección.

🧠 7️⃣ Búsquedas Avanzadas

MongoDB permite combinar operadores lógicos y de comparación para realizar consultas complejas.

Buscar artículos caros y con poco stock

db.productos.find({
  precio: { $gt: 50.00 },
  stock: { $lt: 20 }
}, 
{ nombre: 1, stock: 1, _id: 0 }
).pretty()

Esto mostrará solo el nombre y el stock de los productos que cumplan ambas condiciones (AND implícito).

🚀 7️⃣ Resumen General del CRUD en MongoDB Shell

Ya dominas las cuatro operaciones básicas de cualquier base de datos: CRUD → Create · Read · Update · Delete. A continuación tienes un resumen claro con los comandos más usados, su función y ejemplos prácticos.

🔤 Operación 📘 Descripción 💻 Comando MongoDB Shell 🎯 Resultado
C — Create Inserta uno o varios documentos nuevos. db.productos.insertMany([{ nombre:"Taza", precio:12.5 }]) Crea la colección si no existe y añade los documentos.
R — Read Consulta los documentos guardados, con o sin filtros. db.productos.find({ categoria:"ropa" }, { nombre:1, _id:0 }) Muestra los productos de la categoría “ropa” con solo el campo nombre.
U — Update Modifica valores de uno o varios documentos existentes. db.productos.updateOne({ nombre:"Taza" }, { $inc:{ stock:5 } }) Aumenta el stock del producto “Taza” en 5 unidades.
D — Delete Elimina documentos según un filtro. db.productos.deleteMany({ activo:false }) Borra todos los productos inactivos.

💡 Consejo:

  • Las operaciones CRUD se ejecutan directamente sobre la colección seleccionada (por ejemplo, db.productos).
  • MongoDB crea automáticamente la colección la primera vez que insertas un documento.
  • El orden más lógico para aprender es: Create → Read → Update → Delete.

🎓 Mini-repaso guiado

  1. 👉 Inserta 2 productos nuevos con insertMany().
  2. 🔍 Búscalos con find() filtrando por categoría.
  3. ✏️ Cambia el precio de uno usando $set.
  4. 🗑️ Elimina los productos con stock: 0.
  5. 📊 Comprueba cuántos quedan con countDocuments().
