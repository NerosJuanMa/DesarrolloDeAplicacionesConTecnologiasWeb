Colecciones y Documentos en MongoDB: El Fundamento CRUD

¡Bienvenidos! Aquí entenderemos el corazón de MongoDB: la diferencia entre Colección (el contenedor) y Documento (el dato), y cómo usar la sintaxis básica del Shell para CRUD (Crear, Leer, Actualizar, Borrar).

🗺️ 0️⃣ El Mapa Mental: De Cluster a Documento

Antes de empezar, debemos entender la jerarquía de almacenamiento en MongoDB, especialmente si vienes del mundo SQL. Piénsalo como una estructura de carpetas:

Concepto MongoDB Analogía SQL Lo que Contiene
Cluster (Servidor) ☁️ Servidor / Instancia Bases de Datos (DB)
Base de Datos (DB) Base de Datos Colecciones
Colección 📦 Tabla Documentos (datos)
Documento 📄 Fila / Registro Campos (atributos)

☁️ ¿Qué es un Cluster en MongoDB Atlas?

Un Cluster es la infraestructura distribuida que aloja tus bases de datos. No es solo un ordenador, sino una red de servidores que garantiza que tus datos sean:

  • Seguros: Los datos se replican (copian) en varios lugares.
  • Disponibles: Si un servidor falla, otro lo reemplaza automáticamente.

✅ Solo lo creas una vez en MongoDB Atlas. Dentro de tu Cluster activo, podrás crear y gestionar tus Bases de Datos.

📦 1️⃣ Colección y 📄 2️⃣ Documento: Los Protagonistas

📦 La Colección (Tu Carpeta de Datos)

Una Colección es el contenedor lógico de documentos. Es el equivalente a una Tabla SQL, pero con una diferencia CLAVE: los documentos dentro no tienen por qué tener la misma estructura.

  • Ejemplo: La colección se llamará `productos`.
  • Sintaxis: Siempre la nombras en minúsculas y plural, siguiendo la convención de la comunidad (ej. `db.productos`).

📄 El Documento (Tu Dato Completo)

Un Documento es el registro individual, un objeto escrito en formato JSON (o BSON en memoria). Es la Fila de SQL, pero con campos flexibles.

Ejemplo: Alumno (Documento en la colección `alumnos`)

{
  "nombre": "Laura López",
  "edad": 22,
  "curso": "Full Stack",
  "ciudad": "Sevilla",
  "activo": true
}

Ejemplo: Producto (Documento en la colección `productos`)

{
  "nombre": "Camiseta React",
  "precio": 19.99,
  "stock": 50,
  "categoria": "ropa",
  "activo": true
}

🧪 3️⃣ El CRUD: Creación de Datos (INSERT)

La operación de Creación (CREATE) o Inserción (INSERT) es el primer paso. Aquí es donde debes prestar más atención a la sintaxis del Shell.

La Sintaxis de Oro del MongoDB Shell

Todos los comandos que verás aquí y en el resto del CRUD siguen este patrón:

db.nombreColeccion.metodo(argumentos)
  • `db`: Es una palabra reservada que representa tu Base de Datos actual. ¡Siempre empieza por `db`!
  • `.nombreColeccion`: El nombre de la carpeta donde quieres guardar el dato (ej. `.productos`).
  • `.metodo()`: La acción que quieres ejecutar (ej. `.insertOne()`).

Importante: ¿Cuándo se Crea la Colección?

¡Atención! En MongoDB, NO existe un comando `CREATE COLLECTION`. La colección se crea de forma implícita y automática en el momento en que se inserta el primer documento.

Método 1: Inserción de un Único Documento (`insertOne`)

Utiliza este método para añadir un solo documento. El argumento es el objeto JSON que quieres guardar.

// Comando: Insertar UN solo documento en la colección 'productos'
db.productos.insertOne({
  nombre: "Auriculares Bluetooth",
  precio: 35.0,
  stock: 100,
  categoria: "tecnologia",
  activo: true
});

Método 2: Inserción de Varios Documentos (`insertMany`)

Es más eficiente si quieres añadir varios documentos a la vez. El argumento debe ser una lista (array `[]`) que contiene los objetos JSON a insertar.

// Comando: Insertar VARIOS documentos en la colección 'productos'
db.productos.insertMany([
  { nombre: "Camiseta React", precio: 19.99, stock: 50, categoria: "ropa" },
  { nombre: "Taza JavaScript", precio: 9.5, stock: 120, categoria: "accesorios" }
]);

✅ Las Tres Formas de Insertar Datos (Tu Rutina Profesional)

Aunque usamos el Shell para practicar, en un proyecto real la inserción se hace desde tu código. Aquí están las 3 vías:

Vía Uso Principal Forma Profesional
1. MongoDB Shell 🧠 Pruebas, chequeos rápidos o tareas administrativas. `db.coleccion.insertOne(...)`
2. Código (Mongoose/ORM) 💻 ¡El 99% de tu trabajo! Construir la API y gestionar las interacciones del usuario. `await Modelo.create(...)`
3. Importación de Archivos 📤 Carga inicial de datos grandes (.json, .csv) en un nuevo proyecto. `mongoimport` o herramientas de Atlas.
Tu Foco: La Inserción desde el Código.
En el próximo tema aprenderás a usar Mongoose (para Node.js). Con Mongoose, tu código recibe los datos del usuario y usa el método `.save()` o `.create()` para llevarlos al Cluster. Esto es lo que se hace en la industria.

🔍 4️⃣ El RUD: Leer (Buscar) Documentos

La lectura de datos se hace con el método `.find()`. Es el equivalente al `SELECT` de SQL.

Sintaxis: `db.coleccion.find(filtro)`

Buscar TODO (El SELECT *)

db.productos.find(); 
// Si dejas los paréntesis vacíos, trae todos los documentos.

Buscar con Filtro (El WHERE)

db.productos.find({ activo: true }); 
// Busca todos los productos donde el campo 'activo' sea true.

Extras: Ordenar y Contar

// Ordenar por precio ascendente (1) o descendente (-1)
db.productos.find().sort({ precio: 1 }); 

// Usando operadores: Buscar los que tengan un precio MENOR O IGUAL ($lte) a 20
db.productos.find({ precio: { $lte: 20 } });

✏️ 5️⃣ El CUD: Actualizar Documentos

Para modificar datos, usamos los métodos `updateOne()` y `updateMany()`. Es OBLIGATORIO usar un Operador de Actualización para indicarle a MongoDB cómo cambiar el dato. El más común es `$set`.

Sintaxis: `db.coleccion.updateOne(filtro, { operador: { ... } })`

Actualizar UNO (`updateOne`)

Solo cambia el primer documento que cumpla el filtro.

db.productos.updateOne(
  { nombre: "Taza JavaScript" }, // Filtro: ¿Qué documento?
  { $set: { precio: 10.0 } }      // Operador: Cambia el precio a 10.0
);

Actualizar VARIOS (`updateMany`)

Cambia todos los documentos que cumplan el filtro.

db.productos.updateMany(
  { categoria: "ropa" }, 
  { $inc: { stock: 10 } } // Operador: Suma 10 al stock de TODA la ropa
);

🗑️ 6️⃣ El CRD: Borrar Documentos

Para eliminar registros, usamos `deleteOne()` o `deleteMany()`. ¡No hay vuelta atrás, úsalo con mucho cuidado!

Sintaxis: `db.coleccion.deleteMany(filtro)`

Borrar UNO (`deleteOne`)

db.productos.deleteOne({ nombre: "Camiseta React" });

Borrar VARIOS (`deleteMany`)

db.productos.deleteMany({ activo: false }); 
// Borra todos los productos que hemos marcado como inactivos.

⚠️ ¡Peligro! El borrado en MongoDB no se puede deshacer. Siempre revisa bien tu filtro antes de ejecutar un `deleteMany()`.

🧰 7️⃣ Trucos Esenciales del Shell

Comandos adicionales que te serán muy útiles en tu día a día:

// 1. Proyección: Muestra SOLO los campos 'nombre' y 'precio'
db.productos.find({}, { nombre: 1, precio: 1, _id: 0 }); // El _id: 0 oculta el ID por defecto.

// 2. Contar: Averigua cuántos documentos cumplen el criterio
db.productos.countDocuments({ categoria: "ropa" });

// 3. Paginación: Para ver los datos en partes (p. ej., primeros 10)
db.productos.find().skip(0).limit(10);

🌟 10 Métodos Fundamentales: La Guía Rápida del CRUD

Estos son los comandos esenciales que debes memorizar. Son la base de las operaciones en MongoDB, tanto si trabajas directamente en la consola (Shell) como si programas con Mongoose. Hay muchos más y muchos más operadores pero recuerda que Roma no se construyó en una semana. Empieza por dominar estos y luego ve ampliando tu repertorio.

CRUD Función Sintaxis en MongoDB Shell (Prueba) Sintaxis en Mongoose (Profesional)
CREAR (INSERTAR)
CREATE Inserta un documento. db.productos.insertOne({ ... }) await Producto.create({ ... })
CREATE Inserta varios documentos a la vez. db.productos.insertMany([ {..}, {..} ]) await Producto.insertMany([ {..}, {..} ])
READ (LEER / BUSCAR)
READ Busca uno o más documentos (el SELECT básico). db.productos.find( {filtro} ) Modelo.find( {filtro} )
READ Busca solo el primer documento que coincida. db.productos.findOne( {filtro} ) Modelo.findOne( {filtro} )
UPDATE (ACTUALIZAR)
UPDATE Actualiza solo el primer documento que coincida. db.productos.updateOne( {filtro}, {$set: {..}} ) Modelo.updateOne( {filtro}, {$set: {..}} )
UPDATE Actualiza todos los documentos que coincidan. db.productos.updateMany( {filtro}, {$inc: {..}} ) Modelo.updateMany( {filtro}, {$inc: {..}} )
DELETE (BORRAR)
DELETE Borra solo el primer documento que coincida. db.productos.deleteOne( {filtro} ) Modelo.deleteOne( {filtro} )
DELETE Borra todos los documentos que coincidan. db.productos.deleteMany( {filtro} ) Modelo.deleteMany( {filtro} )
UTILIDAD ESENCIAL
COUNT Cuenta cuántos documentos cumplen un filtro. db.productos.countDocuments( {filtro} ) Modelo.countDocuments( {filtro} )

Recuerda la clave: En el Shell usas db.nombre_coleccion. En Mongoose (código) usas Modelo (con mayúscula y singular, por convención, como Producto).

🎬 8️⃣ Práctica Guiada: Explorando Datos Reales (`muestra_mflix`)

¡Antes de ensuciarnos las manos creando nuestros propios datos, vamos a investigar una base de datos real! MongoDB Atlas te regala la base muestra_mflix, una simulación de plataforma de películas, ideal para practicar el READ (Lectura/Búsqueda) sin riesgo.

Objetivo: Practicar el cambio de base de datos (`use`), el conteo (`countDocuments`), la búsqueda (`find`) y la proyección (`{campo: 1}`).

  1. Paso 1: Conectarse a la Base de Datos de Ejemplo

    Debes decirle al Shell que quieres trabajar en la BBDD de películas, no en la tuya (`mi_tienda`).

    // ⭐️ Palabra Reservada: Te conecta a la Base de Datos 'muestra_mflix'
use muestra_mflix

    El Shell responderá: switched to db muestra_mflix.

  2. Paso 2: Inspeccionar una Colección y Contar Documentos

    Vamos a usar la colección `comentarios`. Primero, verificamos cuántos documentos (comentarios) tiene la colección.

    // Cuenta cuántos documentos hay en la colección 'comentarios'
db.comentarios.countDocuments({})

    *(Deberías obtener un número grande, ¡cerca de 41.000!)*

  3. Paso 3: Leer Todo y Limitar Resultados (`.find()` y `.limit()`)

    Ejecuta tu primer `SELECT *` para ver un documento real. IMPORTANTE: Si no limitas el resultado, la consola se llenará. Por eso usamos el método `.limit()`.

    // Encuentra TODOS los documentos, pero solo muestra los primeros 5
db.comentarios.find().limit(5)

    ⭐ Tip: Observa el campo `_id`. Este es el identificador único que MongoDB asigna automáticamente a cada documento.

  4. Paso 4: Buscar con Filtro y Proyección (Lectura Avanzada)

    Queremos encontrar comentarios de un autor específico, y solo mostrar el nombre y el texto del comentario. Esto se llama Proyección.

    // Filtra los comentarios donde el 'name' sea "John Smith"
// Y proyecta (muestra) solo los campos 'name' y 'text'. 
db.comentarios.find(
  { name: "John Smith" }, 
  { name: 1, text: 1, _id: 0 } // El 1 significa "mostrar", el 0 significa "ocultar"
).limit(3)

¡Felicidades! Acabas de ejecutar las operaciones de lectura más comunes del CRUD sobre una base de datos profesional. Esto es el 90% del trabajo de consulta de datos en el mundo real.
