Tema 8

CRUD con Mongoose en Node.js

Lleva tus conocimientos de MongoDB al siguiente nivel: crea, lee, actualiza y borra datos desde tu aplicación Node.js de forma profesional.

🔍 1️⃣ ¿Qué es Mongoose?

Mongoose es una librería de Node.js que sirve para conectarse a MongoDB y trabajar con sus colecciones de forma más estructurada.

Proporciona una capa de abstracción llamada ODM (Object Data Modeling), similar a un ORM pero para bases de datos NoSQL.

  • 📄 Permite definir modelos con campos, tipos de datos y validaciones.
  • 🔐 Evita errores comunes (como insertar datos sin formato correcto).
  • ⚙️ Facilita las operaciones CRUD con métodos sencillos.
  • 📊 Se integra perfectamente con Express y otras herramientas backend.

Ejemplo mental: En Mongo Shell escribías db.productos.insertOne(...). Con Mongoose harás lo mismo con JavaScript puro:

const nuevo = new Producto({ nombre: "Taza JS", precio: 12.5 });
await nuevo.save();

⚙️ 2️⃣ Instalación y configuración básica

Primero, asegúrate de tener tu proyecto Node.js inicializado (ya con npm init -y y server.js).

Instalar Mongoose

npm install mongoose

Configurar conexión con MongoDB

Dentro de tu archivo server.js, importa Mongoose y conecta usando las variables del archivo .env:

import express from "express";
import mongoose from "mongoose";

const app = express();
app.use(express.json());

const uri = process.env.MONGO_URI;
const user = process.env.MONGO_USER;
const pass = process.env.MONGO_PASS;

mongoose.connect(uri, { user, pass })
  .then(() => console.log("✅ Conectado a MongoDB Atlas con Mongoose"))
  .catch(err => console.error("❌ Error de conexión:", err));

app.listen(3000, () => console.log("🚀 Servidor activo en http://localhost:3000"));

💡 Consejo: Mongoose administra automáticamente la conexión. Si la base de datos no existe, la crea al guardar el primer documento.

🏗️ 3️⃣ Creando un Modelo (Schema)

En Mongoose, los datos se definen mediante esquemas. Un esquema indica qué campos tendrá cada documento, su tipo y posibles valores por defecto.

📂 Archivo: models/Producto.js

import mongoose from "mongoose";

// Definición del esquema
const productoSchema = new mongoose.Schema({
  nombre:      { type: String, required: true, trim: true },
  precio:      { type: Number, required: true, min: 0 },
  stock:       { type: Number, default: 0 },
  categoria:   { type: String, default: "general" },
  activo:      { type: Boolean, default: true },
  descripcion: { type: String }
}, { timestamps: true });

// Creación del modelo asociado a la colección 'productos'
export default mongoose.model("Producto", productoSchema, "productos");

🧠 En resumen:

  • 📦 Schema → define la estructura (campos, tipos, validaciones).
  • 🔗 Model → se usa para ejecutar operaciones CRUD sobre la colección.
  • 📅 La opción { timestamps: true } añade automáticamente createdAt y updatedAt.

📥 4️⃣ Crear (Create)

Para insertar un documento en la colección, usa el modelo y su método create() o save().

import Producto from "./models/Producto.js";

// Método 1: usando .create()
const nuevo = await Producto.create({
  nombre: "Taza Node.js",
  precio: 15.99,
  stock: 30,
  categoria: "accesorios"
});

// Método 2: usando .save()
const prod = new Producto({
  nombre: "Sudadera Mongoose",
  precio: 45,
  stock: 12,
  categoria: "ropa"
});
await prod.save();

console.log("✅ Productos insertados correctamente");

💡 Consejo: Si el esquema marca un campo como required y no lo envías, Mongoose no permitirá guardar el documento.

👁️ 5️⃣ Leer (Read)

Para obtener los datos guardados, usamos métodos como find(), findOne() o findById().

// Leer todos los productos
const productos = await Producto.find();

// Leer solo los activos
const activos = await Producto.find({ activo: true });

// Buscar uno por nombre
const taza = await Producto.findOne({ nombre: "Taza Node.js" });

// Buscar por ID
const porId = await Producto.findById("654c2f0a4d0b8e2b5f9a02e1");

console.log(productos);

El método find() devuelve un array de documentos (aunque solo haya uno).

✏️ 6️⃣ Actualizar (Update)

Mongoose permite modificar documentos existentes con métodos como:

  • updateOne() → actualiza el primero que cumpla la condición.
  • updateMany() → actualiza todos los que cumplan la condición.
  • findByIdAndUpdate() → busca por ID y actualiza directamente.
// Cambiar precio de un producto
await Producto.updateOne(
  { nombre: "Taza Node.js" },
  { $set: { precio: 17.99 } }
);

// Aumentar stock de todos los de ropa
await Producto.updateMany(
  { categoria: "ropa" },
  { $inc: { stock: 5 } }
);

También puedes devolver el documento actualizado con la opción { new: true } en findByIdAndUpdate().

🗑️ 7️⃣ Borrar (Delete)

Eliminar documentos es tan sencillo como en el Shell, pero con métodos propios de Mongoose:

// Eliminar un solo producto
await Producto.deleteOne({ nombre: "Libreta Desarrollo" });

// Eliminar varios inactivos
await Producto.deleteMany({ activo: false });

// Eliminar por ID
await Producto.findByIdAndDelete("654c2f0a4d0b8e2b5f9a02e1");

⚠️ Precaución: Igual que en el Shell, estas operaciones son permanentes. Si quieres desactivar productos sin borrarlos, usa un campo activo: false.

🎯 8️⃣ Resumen CRUD con Mongoose

Operación Método Mongoose Equivalente en Mongo Shell
Create Producto.create() db.productos.insertOne()
Read Producto.find() db.productos.find()
Update Producto.updateOne() db.productos.updateOne()
Delete Producto.deleteOne() db.productos.deleteOne()

  • Has conectado tu aplicación al cluster de Atlas.
  • Has creado un modelo (Producto) con validaciones.
  • Has ejecutado las cuatro operaciones CRUD con métodos profesionales.
