	db.productos.find({ activo: true })	(true=1, false=0)

// Si dejas los paréntesis vacíos, muestra todos los documentos.
	db.productos.find()

// Precio MENOR o IGUAL que 20
	db.productos.find({ precio: { $lte: 20 } })

// Precio MAYOR que 30
	db.productos.find({ precio: { $gt: 30 } })

// Precio ENTRE 10 y 25
	db.productos.find({ precio: { $gte: 10, $lte: 25 } })	

// Orden ascendente por precio (1 = ascendente, -1 = descendente)
	db.productos.find().sort({ precio: 1 })

// Limitar resultados
	db.productos.find().limit(5)

// Saltar los primeros N documentos (paginación)
	db.productos.find().sort({ precio: 1 }).skip(5).limit(5)

// Contar todos los documentos
	db.productos.countDocuments({})

// Contar solo los activos
	db.productos.countDocuments({ activo: true })

// Contar los de una categoría concreta
	db.productos.countDocuments({ categoria: "ropa" })

//******Tip profesional: Combina find() con sort(), limit() y countDocuments() para inspeccionar grandes colecciones sin sobrecargar la consola ni el servidor.

Para seleccionar documentos cuyo nombre empiece por "Camiseta", puedes usar una expresión regular (regex) en MongoDB:
	db.productos.find({ nombre: /^Camiseta/ })
Encuentra los documentos que tengan en su nombre al menos una parte (Camiseta)
 	db.productos.find(
	...   { nombre: /^Camiseta/ },
	...   { nombre: 1, precio: 1, _id: 0 })
Devuelve:
	[.. )
  	{ nombre: 'Camiseta básica', precio: 9.99 },
 	{ nombre: 'Camiseta de vestir', precio: 15.5 }
	]	
si usamos la i, no diferencia entre mayusculas y minusculas:
	db.productos.find({ nombre: /^camiseta/i })
